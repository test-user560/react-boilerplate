# React 초보자 학습 안내 설계

## 목표

처음 React를 접하는 사람이 현재 프로젝트에서 화면 구조, JavaScript 로직, CSS의 위치를 구분하고 다음 학습 행동을 스스로 선택할 수 있게 한다.

## 변경 범위

- `README.md`에 파일 흐름, 역할별 코드 위치, 검색어, 공식 참고 자료, AI 요청 예시를 추가한다.
- `src/main.jsx`, `src/App.jsx`, `src/App.css`, `src/index.css`에 각 파일의 역할을 설명하는 주석을 보강한다.
- 화면 기능과 디자인은 바꾸지 않는다.

## 문서 구성

1. `main.jsx → App.jsx → App.css → index.css` 순서로 읽는 흐름을 설명한다.
2. `App.jsx` 안에서 JSX는 `return (...)`에, JavaScript 로직은 컴포넌트 함수의 `return` 위에 작성한다는 기준을 예시와 함께 설명한다.
3. 자주 막히는 작업별로 한국어 검색어를 제시하고 MDN과 React 공식 문서를 정확한 참고 자료로 연결한다.
4. AI에게 요청할 때는 현재 파일, 원하는 동작, 유지할 조건, 확인 방법을 함께 전달하도록 복사 가능한 예시를 제공한다.

## 완료 기준

- 초보자가 새 버튼을 만들 때 어느 파일에 화면·동작·스타일을 각각 작성할지 README만 읽고 판단할 수 있다.
- 검색어와 AI 요청 예시가 특정 기능 하나에만 묶이지 않고 다음 실습에도 재사용 가능하다.
